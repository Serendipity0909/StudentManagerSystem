from (
  select (stu_name||'|'||school||'|'||class_name||'|'||exam||'|'||
          scores::text||'|'||ranks::text||'|'||total::text||'|'||

## 踩坑记录

`scores` / `ranks` 在云端是 **jsonb**（不是数组）。直接 `array_to_string(scores, ',')`
会报 `DATABASE_42883: function array_to_string(jsonb, unknown) does not exist`。
必须用 `scores::text`。
